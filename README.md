# Cars Dealership - Full-Stack Evaluation Microservices Application

## Project Overview
This project is a full-stack web application for a national car retailer, Cars Dealership. It features microservices for product management, dealer evaluation, dealer pricing, and sentiment analysis.

## Tech Stack
* **Frontend:** React, HTML5, CSS3, JavaScript
* **Backend:** Django, Node.js, Express, Flask
* **Databases:** MongoDB, SQLite
* **Deployment & DevOps:** IBM Cloud Code Engine, Docker, GitHub Actions CI/CD
